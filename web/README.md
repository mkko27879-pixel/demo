# 论文问答前端（Streamlit）

后端接口的图形界面：上传论文、流式问答、查看检索过程和引用来源。
风格参照 DeepSeek——白底 + 蓝紫主色（`#4D6BFE`）、大圆角、答案上方一个可展开的「检索 N 轮」折叠块。明暗主题可在右上角切换。

## 跑起来

先在项目根目录启动后端：

```powershell
uv run uvicorn main:app --reload
```

再启动前端（**必须 cd 到 web 目录**，否则 `.streamlit/config.toml` 里的主题不会被读到）：

```powershell
cd web
..\.venv\Scripts\python.exe -m streamlit run streamlit_app.py
```

浏览器打开 http://localhost:8501。后端地址默认 `http://127.0.0.1:8000`，可以用环境变量覆盖：

```powershell
$env:BACKEND_URL = "http://127.0.0.1:8000"
```

## 目录

```
web/
├── streamlit_app.py        页面脚本（从上到下的直接脚本，逻辑都在下面的模块里）
├── api_client.py           后端 API 封装，包括 SSE 流式解析
├── ui.py                   界面片段：来源卡片、检索过程、论文库面板
└── .streamlit/config.toml  DeepSeek 风格主题（明暗两套）
```

## 界面上能做的事

- **提问**：输入框回车，答案逐字流出来。等待第一个字的那几秒会有「正在检索论文库…」的提示，不会干等；生成期间输入框会变成停止按钮，长回答可以中断。
- **追问**：同一会话内直接接着问，历史由后端保存。
- **加论文**：把 PDF 拖进输入框，或者直接把 arXiv 链接粘进去回车——没有单独的「上传」按钮，这两种动作都在对话栏里完成。入库过程会显示进度。
- **看检索过程**：答案上方「检索 N 轮 · 引用 M 处 · N tokens」的折叠块，展开能看到 agent 每一轮实际用的检索问句和命中数。
- **看来源**：答案下方「引用来源」展开后是每条来源的 paper_id、页码、字符区间和片段原文。
- **管理**：侧边栏可以删除论文（向量、元数据、磁盘文件一起清）和历史会话。

## 两个布局上的取舍

**没有用 `st.chat_message`。** 它自带头像，而且没有左右对齐的参数。这里用原生容器自己排：用户消息是右对齐的一个气泡，AI 回答是左对齐的纯文本，两边都不带头像，靠位置和形态区分。

**上传做成了隐式动作。** 拖文件、贴链接都直接进对话栏，不再单独放一个上传按钮——少一个入口，也少一次点按。

## 已知限制

- **来源暂时不能跳原文**。后端已经存了 `page` 和 `page_start`/`page_end`，但还没有暴露 PDF 文件的接口，所以前端只能把位置信息显示出来。要真正跳转高亮，需要在后端加一个 `GET /api/papers/{paper_id}/file` 之类的接口，前端再配 PDF 查看器。
- **看图问答成本很高**。agent 自己判断要不要渲染页面图像，一次约 25 万 tokens（普通问答约 6 千），后端用 `MAX_PAGES_PER_QUERY` 限了次数。
- **单会话内的历史由后端存**，但前端刷新页面后需要从侧边栏重新点进会话才能恢复上下文。
